How it would be traded

  1. Trend filter (cloud): only take LONGs when EMA20>EMA50 (green cloud); SHORTs when below. Never trade against the cloud.
  2. P&F trigger: a double-top breakout (new X column above the last X top) = BUY; a double-bottom breakdown = SELL. P&F removes intraday noise — only genuine ≥N-box moves count.
  3. Entry at the breakout; stop one box below the current column (defined risk); targets from the box-count projection, R:R ≥ 1:2.
  4. No-trade zone: when the cloud is flat/flipping (chop), stand aside — that's where option buyers bleed.
This is a working prototype on live gold data. It is educational, not advice, and not a guarantee — a realistic edge here is a solid, repeatable ~55–65% with good R:R, not the "95%" claimed by course-sellers (those numbers come from repainting indicators & cherry-picked screenshots).
